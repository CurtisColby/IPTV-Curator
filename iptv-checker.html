Host your playlist

NostalgiaTV needs a URL, not a file. Pick a method below.

Option 1 — Your PlexServer (LAN) Easiest

Since you already run a home server, drop the exported .m3u there and serve it with this one-liner. Your playlist will be available at a permanent local URL.

Step 1 — Export your list (click "Export .m3u"), save it as playlist.m3u anywhere on the server.

Step 2 — Run this in that folder (Python is pre-installed on most Linux boxes):

cd /path/to/your/playlist/folder
python3 -m http.server 8765

Step 3 — To keep it running permanently, add it as a systemd service or run it in a Docker container. Or add it to your existing Docker Compose stack:

services:
  playlist-server:
    image: python:3-alpine
    volumes:
      - /path/to/playlist/folder:/data
    working_dir: /data
    command: python3 -m http.server 8765
    ports:
      - "8765:8765"
    restart: unless-stopped

Step 4 — Find your server's local IP (run hostname -I) then paste this into NostalgiaTV:

Replace 192.168.1.100 with your actual server IP. Update the file anytime — NostalgiaTV will pick up the changes on next refresh.

Option 2 — GitHub Gist (anywhere) Free, public

Create a free GitHub account, go to gist.github.com, paste your M3U content, set filename to playlist.m3u, and click "Create public gist". Then click "Raw" and copy that URL into NostalgiaTV.

Note: Gist raw URLs are public. Don't include any personal streams or credentials in the file.

Option 3 — Paste as raw text Quick test

Copy the raw M3U text below and paste it directly into any IPTV app that accepts raw playlist text (some do under "Add as text" or "Paste M3U").
